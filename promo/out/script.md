# Thursday — 인스타 홍보영상 대본

**30초 · 1080×1920 (9:16) · 30fps · H.264 · 120 BPM**

라이트 테마, 아스키 없음. 화면에는 채팅 두 줄과 파란 닷, 글자만 나옵니다. 오피스는 앱의 오피스(`office.scene.ts`)를 같은 치수 그대로 3D로 다시 세운 것이고, 카메라는 드론처럼 계속 움직입니다.
흐름: 일을 맡긴다 → 파란 닷이 떨어지고, 그 자리에서 오피스가 세워진다 → 설스데이가 팀을 한 명씩 웃으며 소개한다 → 자기 얘기에서 웃음 → DONE → 로고.

끝 카드(25.0초~)는 대사 없이 음악만 흐릅니다. 화면에는 **Thursday.**(파란 닷이 마침표), "You talk. / A whole team does the work."(한국어판: "말만 하세요. / 일은 팀이 합니다."), `> npx thursday-agent`가 나옵니다.

### TTS 팁
- 한 줄 = 한 파일로, 파일 이름은 id로 저장하세요 (`sure.wav`, `meet.wav` …).
- 길이가 넘치면 speed를 1.05~1.15로 올리거나 문장을 줄이면 됩니다. 짧은 건 괜찮습니다. 시작만 맞으면 됩니다.
- 지시문 예시(`me`): *"Playful and warm, like sharing a little secret. End with a short, soft laugh."*
- 영상 자막은 목소리와 상관없이 단어 단위로 빠르게 나타나서, 말 속도가 조금 달라도 어색하지 않습니다.

### 목소리 얹기
```
./add-voice.sh thursday-en.mp4 voices-en/ thursday-en-final.mp4
```
id 이름의 클립을 슬롯 시간에 놓고, 기존 음악·효과음과 섞은 뒤 인스타 기준(−14 LUFS)으로 맞춥니다. ffmpeg가 필요합니다. 같은 시간표가 `voice-cues-en.srt` / `voice-cues-ko.srt`에도 있어서, 편집 툴에서 직접 얹을 때 가이드로 쓰면 됩니다.

## 파일

| 파일 | 내용 |
|---|---|
| `thursday-en.mp4` / `thursday-ko.mp4` | 영상 + 음악 + 효과음 (목소리 자리 비움, 음악 덕킹됨) |
| `stems/music.wav`, `stems/sfx.wav` | 덕킹 전 음악, 효과음 따로 (직접 믹스할 때) |
| `stems/music-sfx-ducked.wav` | 영상에 들어간 오디오 그대로 (음악+효과음, 목소리 자리 덕킹) |
| `voice-cues-en.srt`, `voice-cues-ko.srt` | 목소리 슬롯 |
| `add-voice.sh` | 클립 얹기 + 라우드니스 |

음악과 효과음은 오실레이터와 노이즈로 직접 합성했습니다(D장조, 120BPM). 샘플이나 라이선스 음원은 쓰지 않았습니다.
